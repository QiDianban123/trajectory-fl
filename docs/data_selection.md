# D1 数据选型记录：highD

**决策：** 选定 highD 作为唯一主公开数据集。**负责人：** B；**日期：** 2026-08-31；**状态：** 已记录，待 D3 实际字段探查确认。

## 选择理由

highD 提供高速公路车辆轨迹及帧级运动信息，适合建立连续历史—未来序列；其道路位置和车道等空间信息可解释地构造模拟 RSU 的 Non-IID 客户端。单数据集策略符合 P0 的时间和算力约束。

## D1 已验证与待验证项

| 项目 | D1 结论 | D3 验证动作 |
|---|---|---|
| 本地原始数据 | 当前仓库没有原始 CSV；这是允许状态 | 合法取得数据后运行 `python scripts/probe_highd.py data/raw` |
| 最小字段 | 处理接口以 `id`、`frame`、`x`、`y` 为必需；速度、车道、道路位置为可选 | 对真实表头做映射记录，缺字段时中止并提示 |
| 时间顺序 | 以 frame 单调递增为准 | 统计重复/乱序帧并实施清洗策略 |
| Non-IID 依据 | 优先道路空间区域，其次车道/车辆 | 产出每客户端样本数、区域、车辆数和位置分布 |
| 可复现 | 不提交原始大数据 | 保存数据版本、文件清单、校验值和 split_id |

## 备选与触发条件

若 D3 无法获得合法可读的 highD 样本，或真实字段无法满足连续二维轨迹构造，A/B 在当天重新评审 Argoverse 或 NGSIM；更换必须更新本记录、`requirements.md` 和 Backlog，并保留原决策原因。

## 安全与合规

原始数据及其许可条款由使用者按数据提供方要求取得和保管。仓库只保留准备说明、最小可再分发样例和处理后的统计摘要；`data/raw/` 与 `data/processed/` 均被 Git 忽略。
