# S3-C-01：客户端模型隔离与本地训练兼容

- 阶段：S3（D7—D8）
- 角色：C，模型与训练开发
- 分支：`feature/s3-c-client-training-state`
- 主评审：E；协作：D
- 关联：F3、F5、AT-05、AT-06

## 目标

使共享 Trainer 支持 local epochs，并确保每个客户端模型从同一基线状态独立初始化。

## D7

- 生产代码：实现模型工厂、初始 state clone/hash 和每客户端新实例创建。
- 测试：客户端间无参数/存储共享，顺序变化不改变初始状态。
- 建议提交：`feat(model): add isolated model factory [S3-C-01][F5]`。

## D8

- 生产/联调：支持 local epochs、梯度裁剪和 ClientUpdate 所需训练统计。
- 测试：本地训练稳定性、state_dict 兼容和 checkpoint envelope。
- 建议提交：`test(training): verify client state isolation [S3-C-01][AT-05]`。

## 交付与验收

- Local-only/Federated 不复制 Trainer 循环；模型结构完全一致。
- 任一客户端训练结果不会成为另一客户端初始状态。
- 与 D 的 Client/FedAvg 状态校验全部通过。
