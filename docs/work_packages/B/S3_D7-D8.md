# S3-B-01：客户端 DataLoader 与 Non-IID 数据核验

- 阶段：S3（D7—D8）
- 角色：B，数据工程开发
- 分支：`feature/s3-b-client-dataloaders`
- 主评审：F；第二评审：D
- 关联：F4、F5、AT-04、AT-05

## 目标

为每个 RSU 构建隔离 DataLoader，并确保 FedAvg 权重来自实际有效训练样本数。

## D7

- 生产代码：按 partition manifest 创建 per-client train/val/test loader 和样本计数。
- 测试：客户端并集、交集、空客户端、重复样本和稳定排序。
- 建议提交：`feat(data): build client dataloaders [S3-B-01][F4]`。

## D8

- 生产/诊断：增加极端 Non-IID 小样例和客户端数据画像。
- 测试：核对 ClientUpdate.sample_count 与实际样本访问数；协助人工 FedAvg 权重检查。
- 建议提交：`test(data): verify client sample weights [S3-B-01][AT-05]`。

## 交付与验收

- 客户端数据隔离、并集完整、样本不重复；空客户端不参与训练。
- sample_count 不使用 batch 数或原始行数替代。
- 分布统计可导出并由 D/F 复核。
