- **输出**：任务边界＝D3（partition 配置/区域边界/分组索引/rsu ID + 四类测试）与 D4（空间 Non-IID 分配/相邻小区域合并/统计/manifest + 并集/交集/泄漏/重建测试），分支 `feature/s1-d-noniid-partition`。
- **人工校验**：与角色分工表第 ④ 行、D.md 原文逐条比对一致。

- **指令**：研读全部相关文档与代码，保证实现不偏离冻结口径、风格与排期。
- **AI 执行**：读取 `docs/S1_D3-D4/{A,B,D,F,G}.md`、`docs/{requirements,design,federated_design,git_workflow,test_plan,backlog}.md`、`docs/daily_records/{D1,D2}.md`、`docs/daily_records/S1_D/D2/*`、`data/开发计划书.md`、`data/开发人员参考清单.md`、`configs/*.yaml`、`src/data/*`、`src/utils/config.py`、`src/federated/contracts.py`、`tests/*`、`README.md` 与 git 历史。

### OP-05 设计决策

- **指令**：确定 partition schema 的字段、边界语义与 D3/D4 功能分界，须满足 F4/AT-04 与 M6（错误可定位）。
- **AI 执行**：起草设计并对照冻结文档：
  - 配置默认 5 客户端、轴 `x`、前缀 `rsu_`、`region_edges: null`（按数据纵向跨度等宽切分）、`min_samples_per_client`（相邻小区域合并阈值，D4 用）；
  - 区域区间采用 **右开 [e_i, e_{i+1})，末区间右闭**；坐标恰等内部边界归右侧区域（确定性）；
  - 分组索引按 (x_min, x_max, repr(id)) 全序排序，输入顺序无关 → 支撑 D4 稳定重建；
  - 车辆按其纵向中点入区，一辆车整体只属一个客户端（不复制/不拆分样本）→ D4 实现；
  - 空区域以占用度 0 显式可见，不静默丢弃（D4 合并）。
- **输出**：设计要点（写入 01 号任务卡完成记录）。
- **人工校验**：边界语义与 `bisect_right` 行为手工推演（0→0、10→1、30→2）一致；`client_id` 与元数据契约类型一致。
