## 二、完成情况

### 1. partition 配置（PartitionConfig + YAML + 校验）

- `src/data/partition.py::PartitionConfig`：冻结分区 schema（轴/客户端数/ID 前缀/显式边界/最小样本阈值），非法值在构造期即报 `PartitionError`。
- `configs/data.yaml` 新增 `partition:` 段（默认 5 客户端、轴 `x`、前缀 `rsu_`、`region_edges: null`＝按数据纵向范围等宽切分、`min_samples_per_client: 1`）。
- `src/utils/config.py::_validate_partition`：纳入 `validate-config` 数据配置校验（必填键、客户端数/最小样本为正整数、显式边界数量与严格递增、数值有限性）。同步更新 `tests/unit/test_config.py` 内联数据 YAML 与新增 2 个 schema 用例。

### 2. 区域边界（equal_width_edges / RegionIndex）

- `equal_width_edges(x_lo, x_hi, num_clients)`：等宽生成 `num_clients + 1` 条边界；退化（零/负纵向跨度）或非法客户端数拒绝。
- `RegionIndex`：一维空间区域索引；**边界语义固定为：除末区间右闭外一律右开**——坐标恰等于内部边界时归属于其右侧区域；范围外/非有限坐标报可定位错误。
- `region_bounds(region_index)` 返回区域覆盖范围；`region_occupancy` 输出每区域分组数（空区域＝0，供 D4 相邻小区域合并使用，不静默丢弃）。

### 3. 分组索引（GroupExtent / build_group_index）

- `GroupExtent`：一辆车（train 分组）的纵向跨度 `x_min/x_max`（米，物理坐标）与窗口样本数 `sample_count`；零宽轨迹与零样本分组合法。
- `build_group_index`：确定性排序（与输入顺序无关，为 D4 稳定重建奠基）；**重复 group 直接拒绝**，非 `GroupExtent` 记录拒绝。

### 4. `rsu_<NN>` ID

- `RegionIndex.client_id(region_index)`：`rsu_` 前缀 + 序号宽度格式化（默认 5 区域 → `rsu_01…rsu_05`），与 TrajectoryMetadata 可选的 `client_id`（字符串）契约一致。
