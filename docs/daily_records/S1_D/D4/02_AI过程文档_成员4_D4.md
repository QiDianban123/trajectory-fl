## 详细操作记录

### OP-01 承接与复读

- **指令**：承接 D3（S1-D-01 上半程，分支 `feature/s1-d-noniid-partition`），完成 D.md「D4」；先复核冻结口径再实现。
- **AI 执行**：复核 `docs/S1_D3-D4/D.md`（D4 节与交付验收）、`docs/federated_design.md §1`（5-RSU 空间映射、相邻合并、不复制样本）、`docs/requirements.md` F4/AT-04、`docs/design.md`（client_id 可选元数据、数据层无模型/联邦依赖）、D3 提交（`5c53dcf`）与 `docs/daily_records/S1_D/D3/*`。
- **输出**：实现边界——输入＝train 分组集合 + `PartitionConfig`；输出＝可重建 `PartitionManifest`（每客户端样本数/车辆数/空间范围）；不变式＝并集完整、交集为空、稳定重建。
- **人工校验**：与冻结文档逐条对照，确认不越界实现 B/G/A 职责。

### OP-02 设计决策

- **指令**：确定 D4 算法语义（须满足“可解释 Non-IID”“相邻小区域合并”“稳定重建”“不复制样本”）。
- **AI 执行**：起草并推演：
  1. **锚定**：车辆纵向中点 `(x_min+x_max)/2` 落入的区域 = 客户端（复用 D3 `RegionIndex` 右开/末区间右闭语义）——一辆车整体属一个客户端，杜绝“复制/拆分样本”；
  2. **合并**：自低 x 扫描样本数低于 `min_samples_per_client` 的区域，并入**相邻且样本更少**的区域（持平取左）；空区域（0 样本）同样参与消融，最终无空客户端；仅剩 1 个客户端时终止；
  3. **退化**：全部车辆同一纵向坐标 → 单客户端、零宽覆盖，不伪造等宽区域；
  4. **manifest**：记录请求边界 + 合并后客户端（id/覆盖/样本/车辆/分组 id），`assignment` 供 B 回填 `meta.client_id`，`to_mapping()` 供 G 并入数据 manifest；
  5. **不变式函数** `check_partition_invariants`：自动化并集完整/交集为空/无外来分组/ID 唯一/样本合计一致。
- **输出**：写入 01 号任务卡完成记录设计表。
- **人工校验**：对小规模样例手工推演合并顺序与结果（见 OP-05 冒烟断言），确认确定性成立。

### OP-09 缺陷回归（用户环境复跑）

- **指令**：用户在成员环境执行 `python -m pytest -q`，结果为 **69 通过 / 2 失败**；要求定位并修复。
- **AI 执行**：读取两处失败栈（`tests/unit/test_config.py::test_data_config_requires_partition_section`、`tests/unit/test_partition.py::test_partition_invariants_reject_incomplete_foreign_or_wrong_counts`）分析：
  1. 删除 `partition` 段后，`_section()` 抛出的文案是 `partition must be a mapping` 而非测试预期的 `partition is missing required keys` → 属缺段错误文案不可定位（M6）+ 断言不匹配。修复：`_validate_data` 对缺失 `partition` 段显式报 `data config is missing the required 'partition' section`，测试同步改为此文案；
  2. `check_partition_invariants` 先检“外来分组”再检“并集缺失”，测试把“输入缺分组”的方向误当作 incomplete（实际触发 `not present`）→ 测试场景方向错误。修复：incomplete 场景改为**输入超集**（输入含分组 3 而 manifest 无）以命中 `client union is incomplete`。
- **输出**：修改 `src/utils/config.py`、`tests/unit/test_config.py`、`tests/unit/test_partition.py`；本地 py_compile 与纯标准库冒烟验证两个方向的消息（incomplete / foreign / sample-count 三类均按预期抛错）。分区算法本身无需改动。
- **人工校验**：确认修复仅涉及错误文案与测试场景方向，不影响任何分区行为；缺陷闭环记录见 `03_QA代码审查自检_成员4_D4.md`（QA-D4-05/06）。
