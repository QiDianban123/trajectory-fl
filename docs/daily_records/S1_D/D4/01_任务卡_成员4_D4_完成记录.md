## 二、设计要点（冻结口径 → 实现）

| 冻结口径（federated_design.md §1） | 本日实现 |
|---|---|
| 仅将训练集按道路纵向空间区域映射至模拟 RSU | `partition_train_groups` 只接受训练分组；manifest 面向 train split |
| 客户端记录区域边界、车辆数、有效训练样本数与坐标统计 | `ClientPartition`（x_min/x_max、group_ids、sample_count） |
| 某区域样本不足时合并相邻区域，不得复制样本填充 | 低于 `min_samples_per_client` 的区域并入**相邻、样本更少**的区域（持平取左侧），不复制任何样本 |
| 空间区域形成可解释 Non-IID | 区域为道路纵向等宽或显式边界带；车辆按其**纵向中点**整体归属一个客户端（不跨客户端拆分） |

- 分配：区域区间 `[e_i, e_{i+1})`（末区间右闭），中点恰在边界归右侧区域（复用 D3 `RegionIndex`）。
- 合并：自低 x 向高 x 逐区扫描低于阈值的区域并入邻区，直至全部区域达标或仅剩 1 个客户端；空区域以 0 样本同样参与合并，**不会出现空客户端**。
- 退化场景：全部分组纵向坐标相同时退化为单客户端（manifest 记录零宽覆盖），不崩溃、不伪造区域。
- 稳定性：输入经 D3 确定性排序；manifest 为输入分组集合与配置的纯函数，乱序/重复运行结果一致。

## 三、生产代码清单（本日）

| 符号 | 说明 |
|---|---|
| `ClientPartition` | 一个客户端：`client_id`、覆盖 `x_min/x_max`、`sample_count`、`group_ids`；构造校验 |
| `PartitionManifest` | 可重建 manifest：请求边界（合并前）+ 合并后客户端序列；`assignment`（分组→客户端映射）、`totals()`、`to_mapping()`（JSON 序列化） |
| `partition_train_groups(groups, config)` | Non-IID 分配 + 相邻小区域合并 + 统计主入口（F4/AT-04） |
| `check_partition_invariants(manifest, groups)` | 自动不变式：并集完整 / 交集为空 / 无外来分组 / 客户端非空且 ID 唯一 / 样本数与输入一致 |

### 示例 manifest（冒烟脚本纯逻辑输出）

6 车辆、5 客户端配置、`min_samples_per_client=20` 时末区域样本不足（15 < 20），与左邻区域合并 → 实际 4 客户端：

```json
{
  "schema_version": 1, "axis": "x",
  "num_clients_requested": 5, "num_clients": 4,
  "region_edges": [0.0, 20.0, 40.0, 60.0, 80.0, 100.0],
  "clients": [
    {"client_id": "rsu_01", "x_min": 0.0, "x_max": 20.0, "vehicle_count": 1, "sample_count": 40, "group_ids": [101]},
    {"client_id": "rsu_02", "x_min": 20.0, "x_max": 40.0, "vehicle_count": 2, "sample_count": 65, "group_ids": [102, 103]},
    {"client_id": "rsu_03", "x_min": 40.0, "x_max": 60.0, "vehicle_count": 1, "sample_count": 25, "group_ids": [104]},
    {"client_id": "rsu_04", "x_min": 60.0, "x_max": 100.0, "vehicle_count": 2, "sample_count": 35, "group_ids": [105, 106]}
  ]
}
```

字段说明：`region_edges` = 请求的等宽边界（合并前）；每客户端 `x_min/x_max` = 合并后的空间覆盖范围；`vehicle_count` = 分组（车辆）数；`sample_count` = 窗口样本数合计（与 federated `sample_count`“实际有效训练样本数”口径一致，供 D7—D8 FedAvg 权重引用）。
