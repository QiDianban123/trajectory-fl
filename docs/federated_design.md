# D1 Non-IID 与 FedAvg 方案草案

## Non-IID 划分

1. 先按车辆 ID 或场景划分 train/validation/test，禁止滑窗后再随机拆分。
2. 仅将训练集按道路纵向空间区域映射至 5 个模拟 RSU；每个客户端记录区域边界、车辆数、样本数与坐标统计。
3. 某区域样本不足时合并相邻区域；不得复制样本填充。车道或车辆分桶仅作次级诊断，不作为默认主划分。
4. `split_id` 由数据版本、车辆/场景切分种子、RSU 边界和过滤规则共同确定。

## FedAvg 契约

第 r 轮，服务端向选中的客户端发送同一全局状态 $w_r$。客户端 i 只用本地训练样本完成 E 个 epoch，上传 $w_{r+1}^i$、实际有效样本数 $n_i>0$ 和统计信息。服务端拒绝空更新、非正样本数、参数键/形状不一致或非有限值，随后计算：

$$w_{r+1}=\sum_{i \in S_r}\frac{n_i}{\sum_{j \in S_r} n_j}w_{r+1}^i$$

浮点参数按上述公式逐元素加权，非浮点 buffer 必须采用明确策略（D2 确定为保留全局值或从最大样本客户端复制）。每轮日志至少记录 round、客户端 ID、样本数、训练损失、验证 ADE/FDE、耗时和失败原因。

## Local-only 与公平性

每个客户端从完全相同的初始模型独立训练，绝不共享参数；使用统一全局测试集和各自测试子集，输出宏平均和按测试样本数加权平均。三种模式复用数据 split、模型定义、seed 和评价实现，计算预算差异必须在结果中显式记录。

对应类型契约：`src/federated/contracts.py`。
