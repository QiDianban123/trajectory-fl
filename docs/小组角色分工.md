# 小组角色分工表

> 项目：异构场景下联邦车辆轨迹预测系统
> 要求（课程 PPT）：7～8 人一组，每人担任 **1 个管理角色 + 1 个非管理（技术）角色**

## 一、角色总表

| 成员 | 管理角色 | 非管理（技术）角色 |
|------|---------|------------------|
| 成员① | 项目经理 / Scrum Master（组长） | 系统架构师（联邦学习框架） |
| 成员② | 产品负责人（PO / 需求管理） | 数据工程师（数据处理与轨迹可视化） |
| 成员③ | 配置管理员（Git / 版本管理） | 算法工程师（轨迹预测模型） |
| 成员④ | 质量保证员（QA / 代码审查） | 联邦实验工程师（三种训练方式） |
| 成员⑤ | 测试经理（测试与缺陷管理） | 评测与可视化工程师（ADE/FDE 与图表） |
| 成员⑥ | 文档与经费管理员 | 测试工程师（测试执行与用户手册） |
| 成员⑦（7人组增设） | 沟通/协调员 | 界面/演示工程师 |
| 成员⑧（8人组增设） | 风险管理/创新专员 | 算法研究员（创新点） |

---

## 二、各角色详细职责

### 成员① 项目经理 / Scrum Master ＋ 系统架构师

**管理职责：**
- 制定项目计划与 3 周进度（甘特图），组织 6 次汇报
- 主持 Sprint 计划会、每日站会、评审会、回顾会
- 协调成员分工、跟进阻塞问题、对外与指导教师沟通
- 对应毕业要求 **9.3（组织协调团队）**

**技术职责：**
- 设计系统整体架构与模块接口
- 实现联邦学习核心框架：服务器端 **FedAvg 聚合**、客户端调度、通信流程
- 搭建 CodeArts 项目空间

**交付物：** 项目计划表、系统架构图、联邦聚合模块代码

---

### 成员② 产品负责人（PO）＋ 数据工程师

**管理职责：**
- 管理 Product Backlog，需求条目化、优先级排序（CodeArts 需求管理）
- 每次迭代验收功能是否达标，代表"甲方"确认需求
- 对应毕业要求 **11（项目管理）**

**技术职责：**
- 读取公开数据集（NGSIM / HighD / Argoverse），完成提取与预处理（缺失值、异常值、归一化、时序切分）
- 实现**多客户端数据划分**（模拟不同路侧单元 RSU，non-IID）
- 实现历史轨迹 + 未来真实轨迹的可视化

**交付物：** 需求规格说明、数据加载/预处理模块、数据划分模块、轨迹可视化图

---

### 成员③ 配置管理员 ＋ 算法工程师

**管理职责：**
- 负责 Git/CodeArts 代码托管：分支策略（main/dev/feature）、合并请求、权限管理
- 制定提交规范，保证每人有持续提交记录
- 对应 PPT"管理工具应用：使用 Git 进行版本管理"

**技术职责：**
- 实现基础轨迹预测模型（LSTM / Seq2Seq，PyTorch）
- 模型输入输出定义（历史轨迹 → 未来轨迹）、训练与推理流程
- 配合联邦框架封装模型本地训练接口

**交付物：** 仓库分支与 MR 记录、预测模型代码、模型训练脚本

---

### 成员④ 质量保证员（QA）＋ 联邦实验工程师

**管理职责：**
- 组织 Code Review，把关代码规范
- 运行 CodeArts 代码检查（CodeCheck），跟踪缺陷修复闭环
- 对应毕业要求 **12.2（自主学习与归纳）**

**技术职责：**
- 实现三种训练流程：**集中式训练 / 各客户端本地独立训练 / 联邦训练**
- 训练超参数调优、loss 收敛分析、训练日志记录
- 保证"数据读取→训练→联邦聚合→结果展示"全流程稳定运行

**交付物：** 代码检查报告、三种训练模式代码、训练日志与对比实验记录

---

### 成员⑤ 测试经理 ＋ 评测与可视化工程师

**管理职责：**
- 制定测试计划，组织功能测试与模型性能测试
- 管理缺陷单（CodeArts 缺陷管理：提出→修复→回归关闭）
- 编写测试分析报告

**技术职责：**
- 实现 **ADE、FDE** 指标计算
- 三种训练方式的结果汇总与对比分析
- 实验结果可视化（指标柱状图、预测轨迹对比图、收敛曲线）

**交付物：** 测试计划、缺陷跟踪记录、指标计算模块、实验结果图表（答辩用图）

---

### 成员⑥ 文档与经费管理员 ＋ 测试工程师

**管理职责：**
- 维护全部文档体系：综合设计文档、会议记录（含照片）、PPT
- 负责 **10 万元虚拟预算表、支出流水、决算表**，每次汇报更新执行进度
- 每周 2 次向乐学提交材料；编写 **AI 工具专项说明文档**（含 Prompt 记录）

**技术职责：**
- 执行功能测试用例与模型性能测试用例，记录测试结果
- 编写**用户使用手册**
- 准备最终答辩的系统 **Demo 演示脚本/演示视频**（防现场故障）

**交付物：** 预算/决算表、会议记录、各次 PPT、用户手册、测试执行记录、AI 使用说明

---

### 成员⑦（7 人组增设）沟通/协调员 ＋ 界面/演示工程师

**管理职责：**
- 负责组内沟通协调、会议组织与通知、会议记录整理
- 协助组长跟进任务进度与跨成员协作

**技术职责：**
- 开发可视化交互界面（Python GUI 或 Web 页面：选择训练方式、展示轨迹与预测结果）
- 分担数据轨迹可视化工作

**交付物：** 交互界面、演示页面

---

### 成员⑧（8 人组增设）风险管理/创新专员 ＋ 算法研究员

**管理职责：**
- 识别项目风险（进度、数据、环境、平台扣费等）并跟踪应对
- 负责创新点材料整理，争取创新分（≤10 分）

**技术职责：**
- 研究创新方向：异构联邦（non-IID）、个性化聚合、模型改进等
- 负责创新实验设计与结果分析

**交付物：** 风险登记表、创新实验代码与分析

---

## 三、补充说明

1. 角色为**主责**划分；联邦框架、模型、数据接口耦合紧密，建议前 3 天全员联调通主流程，再分头迭代。
2. 每人的管理角色和技术角色须在答辩 PPT"分工表"中明确列出，作为毕业要求 9（个人和团队）的打分依据。
3. 所有过程材料（会议记录、经费、看板截图、训练日志、测试记录）**边做边留**，指定专人归档。
